# PixelForge AI - Master Plan

## Development Phases
* **Phase 0:** Repository audit, initialization, dependency installation.
* **Phase 1:** Application foundation (Auth, DB schema, basic API).
* **Phase 2:** Description-to-website generation (Gemini prompt architecture).
* **Phase 3:** Screenshot-to-website generation (Vision AI, upload pipeline).
* **Phase 4:** Professional website editor (Monaco, targeted AI patches).
* **Phase 5:** Secure preview and testing (Iframe sandbox, Playwright).
* **Phase 6:** Import and export (ZIP handling).
* **Phase 7:** Final product quality (UI polish, responsiveness, audit).
* **Phase 8:** Deployment (Netlify, Render, Supabase production).
